# PyScope — Python Codebase Explorer

PyScope — это локальный инструмент статического анализа Python-репозиториев, который генерирует интерактивные отчёты об архитектуре кода. Инструмент помогает разработчикам быстро разобраться в незнакомом кодовом базисе: понять структуру, зависимости, связанность, циклические импорты и потенциальные проблемы поддерживаемости.

## Возможности

- **Статический анализ на основе AST** — чтение и парсинг исходников без импорта и выполнения кода целевого проекта.
- **Обнаружение проекта** — Python-файлы, пакеты, модули, `__init__.py`, точки входа, тестовые каталоги, конфигурация, индикаторы фреймворков.
- **Метрики на уровне файлов, функций и классов** — строки кода, комментарии, аргументы, ветвления, цикломатическая сложность, глубина вложенности, покрытие docstring и аннотациями типов.
- **Анализ импортов и зависимостей** — абсолютные и относительные импорты, разделение на внутренние, стандартную библиотеку, сторонние пакеты и неразрешимые импорты.
- **Граф зависимостей** — ориентированный граф модулей, подсчёт входящих/исходящих зависимостей, центральность, изолированные и сильно связанные модули.
- **Обнаружение циклов** — алгоритм Тарьяна для сильно связанных компонент (SCC), отчёт о циклических зависимостях.
- **Архитектурные рекомендации** — крупные модули, сложные функции и классы, высокая связанность, слабо документированные модули, потенциальные точки входа.
- **Интерактивный HTML-отчёт** — SVG-граф с масштабированием, панорамированием, выделением узлов, поиском, фильтрацией по пакетам, подсветкой циклов, тёмная/светлая темы, переключение языка (RU/EN). Работает локально без сервера и сети.
- **Экспорт** — JSON (версионированная схема 1.0), Graphviz DOT, Mermaid, текстовый терминальный отчёт.
- **Конфигурация** — `pyscope.toml`: шаблоны включения/исключения, пороги сложности, настройки отчёта и графа, игнорируемые импорты.
- **Безопасность** — выполнение кода целевого проекта не производится, не следуем по символическим ссылкам за пределы корня, защита от обхода пути, экранирование HTML.
- **Локализация** — русский по умолчанию, английский как второй язык.

## Быстрый старт

```bash
pip install pyscope
pyscope analyze /путь/к/проекту --output report.html --open
pyscope analyze /путь/к/проекту --format json --output analysis.json
pyscope version
```

### Команды CLI

| Команда | Описание |
|---------|----------|
| `pyscope analyze PATH` | Анализирует проект и создаёт HTML-отчёт |
| `pyscope analyze PATH --format json` | Экспорт в JSON |
| `pyscope analyze PATH --format dot` | Экспорт в Graphviz DOT |
| `pyscope analyze PATH --format mermaid` | Экспорт в Mermaid |
| `pyscope analyze PATH --output report.html` | Куда сохранить отчёт |
| `pyscope analyze PATH --exclude "tests/**"` | Дополнительные шаблоны исключения |
| `pyscope analyze PATH --fail-on-cycles` | Код выхода 2 при наличии циклов |
| `pyscope analyze PATH --open` | Открыть отчёт в браузере |
| `pyscope analyze PATH --language en` | Язык отчёта (ru/en) |
| `pyscope version` | Версия |

## Конфигурация (`pyscope.toml`)

Создайте `pyscope.toml` в корне анализируемого проекта или передайте `--config`:

```toml
exclude_patterns = ["tests/**", "migrations/**"]
respect_gitignore = true
max_file_size = 5000000
complexity_threshold = 10
function_length_threshold = 60
class_method_threshold = 20
docstring_coverage_threshold = 0.6
report_language = "ru"
report_theme = "light"
graph_max_nodes = 500
fail_on_cycles = false
```

## Метрики (como считаются)

Все метрики — heuristic и не являются окончательной оценкой качества кода.

- **Цикломатическая сложность**: 1 + количество точек ветвления (`if`, `for`, `while`, `except`, `with`, `try`, `and`/`or`, условия в компрехенсиях). Вложенные функции не учитываются во внешней функции.
- **Глубина вложенности**: максимальная глубина управляющих конструкций внутри определения.
- **Покрытие аннотациями**: доля аргументов функции с аннотацией типа.
- **Покрытие docstring**: доля публичных функций и классов с docstring.

## Безопасность

- Код целевого проекта не импортируется и не выполняется.
- Не запускаются `setup.py` и не устанавливаются пакеты из целевого репозитория.
- Символические ссылки, ведущие за пределы корня проекта, не следуются.
- Защита от обхода пути (path traversal).
- HTML-контент экранируется; исходный код не внедряется в исполняемый JavaScript.
- Один ошибочный файл не прерывает анализ всего проекта; есть отчёт о пропущенных и неразобранных файлах.

## Ограничения

- Статический анализ не может полностью определить поведение во время выполнения или доказать корректность кода.
- Неразрешимые импорты не всегда являются ошибкой (например, динамические импорты).
- Метрики —heuristics, пороги настраиваются.
